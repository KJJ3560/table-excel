# Plumber Quest

브라우저에서 바로 즐기는 **마리오 스타일 사이드스크롤 플랫포머**입니다.
이미지 파일이나 외부 음원 없이, 모든 그래픽은 `<canvas>` 도형으로, 모든
배경음악/효과음은 오리지널로 작곡·합성한 8비트 스타일 WAV 파일로 구성되어
있습니다. 빌드 도구 없이 정적 파일만으로 동작합니다.

## 실행 방법

오디오 로딩에 `fetch()`를 사용하기 때문에 `index.html`을 파일로 직접 열면
브라우저 보안 정책(CORS)에 막힐 수 있습니다. 간단한 정적 서버로 실행하세요.

```bash
cd mario-game
python3 -m http.server 8000
# 브라우저에서 http://localhost:8000 접속
```

또는 Node가 있다면:

```bash
npx serve mario-game
```

## 조작법

| 동작 | 키 |
| --- | --- |
| 이동 | ← → 또는 A / D |
| 점프 | Space, ↑, 또는 Z (길게 누르면 더 높이 점프) |
| 달리기 | Shift (누른 채 이동 시 더 빠르고 더 멀리 점프) |
| 일시정지 | P |
| 음소거 | M |
| 시작 / 확인 | Enter |

모바일에서는 화면 하단에 가상 방향키와 점프 버튼이 표시됩니다.

## 게임 구성

- 2개의 스테이지(1-1 초원 지대, 1-2 지하 동굴)를 순서대로 클리어하면 승리합니다.
- 코인, `?` 블록, 벽돌 블록, 버섯 파워업(작은 상태 → 큰 상태), 굼바형/가시형
  적, 파이프 장애물, 구덩이, 계단, 깃발+성으로 이어지는 클리어 지점 등 클래식
  플랫포머의 기본 요소를 갖추고 있습니다.
- 점수, 코인 카운트(100개 획득 시 1UP), 남은 시간(0이 되면 사망), 라이프,
  최고 점수(로컬 저장)를 HUD와 타이틀 화면에서 확인할 수 있습니다.

## 오디오

`assets/audio/`의 모든 `.wav` 파일은 `tools/generate_audio.py` 스크립트가
사각파/삼각파/사인파/노이즈를 직접 합성해서 생성한 **오리지널** 음원입니다.
실제 게임 음원을 녹음하거나 추출한 파일이 아니며, 외부 라이브러리 없이
파이썬 표준 라이브러리(`wave`, `struct`, `math`)만 사용합니다.

배경음악은 8마디 루프로 작곡한 새 멜로디이고, 효과음은 점프/동전/밟기/
블록 타격/파워업/피격/사망/깃발/클리어/게임오버/1UP 등을 각각 새로
합성했습니다. 음원을 재생성하거나 다른 사운드로 바꾸고 싶다면 아래 명령을
실행한 뒤 `assets/audio/`를 다시 채우면 됩니다.

```bash
python3 tools/generate_audio.py
```

## 프로젝트 구조

```
mario-game/
├── index.html            진입점
├── css/style.css          레이아웃 및 반응형/터치 컨트롤 스타일
├── js/
│   ├── constants.js        타일 크기, 물리 상수, 테마 색상
│   ├── audio.js             Web Audio API 사운드 매니저
│   ├── input.js              키보드 + 터치 입력 처리
│   ├── entities.js            플레이어/적/아이템/블록 그리기 및 상태
│   ├── level.js                레벨 데이터와 타일맵 빌더
│   ├── game.js                  메인 루프·물리·충돌·상태 머신·렌더링
│   └── main.js                   부트스트랩
├── assets/audio/*.wav      합성된 오리지널 음원
└── tools/generate_audio.py 음원 생성 스크립트
```

## 라이선스 / 저작권 참고

캐릭터·적·블록 등 모든 비주얼은 원과 사각형 등 기본 도형으로 새로 그린
오리지널 그래픽이며, 음원 역시 위에서 설명한 대로 직접 합성한 새 창작물입니다.
특정 회사의 상표, 캐릭터 디자인, 실제 게임 음원을 그대로 사용하지 않았습니다.
